# 🎯 PRECISION — 탭 타이밍 게임

> 원이 경계선에 닿기 **직전**에 탭하세요. 가까울수록 고득점!

**▶ 지금 바로 플레이** → [https://깃허브아이디.github.io/tap-rush](https://github.com)

---

## 🎮 게임 방법

1. **시작하기** 버튼을 누르면 작은 원이 나타납니다
2. 원이 점점 **커지면서 경계선에 가까워집니다**
3. 경계선에 **닿기 직전**에 탭하세요
4. 경계선을 **넘으면 게임 오버** (빨간 폭발 이펙트)
5. 탭할수록 스테이지가 올라가고 원이 더 빠르게 팽창합니다

---

## 🏆 점수 체계

| 등급 | 조건 | 점수 |
|------|------|------|
| ✦ PERFECT | 경계 5% 이내 | 100점 |
| GREAT | 경계 15% 이내 | 60점 |
| GOOD | 경계 30% 이내 | 30점 |
| OK | 경계 50% 이내 | 12점 |
| TOO EARLY | 그 이하 | 2점 |

- **콤보 5회 이상** 달성 시 점수 배율 적용
- 스테이지가 올라갈수록 팽창 속도 증가

---

## ✨ 기능

- 🎨 **6가지 스킨** — 사이버 / 파이어 / 네온 / 로즈 / 골드 / 아이스
- 📊 **개인 기록 저장** — 최고 점수, 평균 근접도, PERFECT 횟수, 최근 20판 히스토리
- 🔊 **사운드 효과** — 등급별 효과음 (PERFECT는 화음!)
- 💥 **파티클 이펙트** — 탭 시 등급에 따른 파티클, PERFECT 시 링 폭발
